# Pokedex

Pokedex developed for the Looqbox challenge.

## Technologies used

- React
- Redux
- React Router
- Ant Design
- TanStack Query
- Vite

## How to run

```bash
npm install # To install dependencies
npm run dev # To run the project
npm run test # To run the tests
```

## Features

- Pokémon listing
- Pokémon search
- Pokémon details
- Infinite pagination
- Responsiveness
